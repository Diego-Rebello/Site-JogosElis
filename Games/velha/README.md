# Jogo da Velha Divertido

Jogo da velha para dois jogadores ou contra o computador, feito em React + Vite.

- `npm install` — instala as dependências.
- `npm run dev` — abre em modo de desenvolvimento.
- `npm run build` — gera a pasta `dist/`, que é commitada no repositório (o Netlify publica o `dist/` como está).
